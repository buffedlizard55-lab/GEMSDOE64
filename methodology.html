Selection protocol · current lane

Optimize the score’s marginal gain, not a pixel threshold.

The only active method is expected-DTI-optimal selection: use spatially held-out evidence to estimate plausible truth, then add or remove candidates according to their exact marginal contribution under the competition’s distance kernel.

!

PROTOCOL DEFINED · COMPETITION EVALUATION NOT RUN

The toy probe passes on synthetic sparse rasters. The official/shared evaluator, holdout labels and raster inputs are missing here. Consequently, there is no competition-scale score, calibration, confidence interval, or cleared output.

Metric context

The published score rewards near coverage and penalizes excess prediction.

The public description specifies a distance-weighted Tversky index, with α = 0.2, β = 0.8, and a linear triangular kernel with R = 300 m. The grid is 100 m. The exact competition/template implementation must be reused when data are available; the expression below is only a concise description of the published weighted counts.

DTI = TPw / (TPw + α·FPw + β·FNw)

For a truth pixel g, distance-kernel support is k(d) = max(1 − d/R, 0). Its coverage is the maximum over candidate pixels of predicted value × kernel weight. Uncovered truth contributes to false negatives; predicted mass not supported by nearby truth contributes to false positives. The tiny synthetic script transcribes this operation for point sets only.

Source: official competition problem description. A worked term example in that description rounds to 0.60; the probe recomputes it as 0.6026516673. This formula check is not an evaluator certification.

Synthetic-only audit · executed 2026-10-11

What the threshold tells us—and what it cannot.

The script scripts/verify_expected_dti_rule.py uses only Python’s standard library. It emits the same results in a machine-readable JSON record. It contains no real fault labels, pixels or competition score.

PASS · ISOLATED TOY

When there is no overlap

In a deliberately isolated unit-count case with baseline score 0.30, the shorthand threshold q > αS is 0.06. A candidate occurring in 7% of synthetic truth draws yields mean score gain +0.00363215; one at 5% yields −0.00363215.

This validates a narrow algebraic intuition, not an optimal competition selector.

COUNTEREXAMPLE · REDUNDANCY

Kernel overlap changes the answer

For two sparse synthetic truth rasters and an existing prediction at pixel 0 and 2, candidate pixel 3 is positive in half the draws. It exceeds α × mean baseline DTI (0.500 vs 0.16888), yet exact mean DTI falls from 0.84440228 to 0.84375.

The exact marginal gain is −0.00065228. The greedy selector correctly rejects it.

Takeaway: a per-pixel occurrence probability is not a safe independent threshold for the expected score when the metric uses a max-over-neighborhood kernel and predicted points compete to cover the same truth. Evaluate the exact marginal DTI change for every plausible truth raster.

Locked method lane

Required run, from spatial validation to a go/no-go.

These are requirements for a future authorized run. None of the competition-data steps below is claimed complete in this checkout.

Pre-register one mechanism and a plausible mimic

Choose from the ranked hypothesis register. State the physical signal, where novelty could arise, available source layers, suspected confounders, and an explicit cost/time budget before inspecting holdout results.

Hide whole fault segments with a spatial buffer

Reuse the shared cached feature stack and evaluator. Build blocked folds around complete segments; derive catalogue features only from visible faults. Mask visible faults pixel-exactly—organizer clarification says nearby unmasked pixels remain scoreable.

Run leakage canaries and calibration

Test every feature alone. Treat a holdout AUC above 0.90 as a leakage warning until explained. Calibrate out-of-fold probabilities by isotonic regression using spatially blocked folds. A high score is not evidence of generalization until leakage checks pass.

Generate plausible truth rasters

Use the specified ensemble/TTA/MC-dropout outputs, including small spatial jitter, to form at least 32 plausible truth surfaces. Record how each draw was generated and keep visible-fault pixels masked as specified.

Select on exact expected marginal DTI

Starting from the incumbent prediction, greedily add the ridge-candidate pixel with the largest mean exact DTI gain over all draws. Prune backward whenever exact marginal gain is non-positive. Compare against the incumbent spacing/MCLP placement on the same surfaces—not a different test set.

Demand uncertainty-aware lift

Use a spatial block bootstrap on the same holdout surfaces. Promotion requires improvement greater than two bootstrap standard errors and a fully reported 95% confidence interval. If the interval or leakage evidence is unclear, stop rather than call a projection a score.

Check novelty against every registered raster

Log rank correlation and the fraction of dots within 3 pixels of each registry raster before placement and after final selection. If correlation exceeds 0.90 or overlap exceeds 70% for any registry entry, mark the run a duplicate and stop.

Validate the exact bytes and close the run card

Use the shared writer/validator; confirm grid, CRS, transform, dimensions, dtype, nodata behavior, finite [0,1] values, and pixel/hash agreement. Store SHA-256, evaluator version, withheld-positive count, 95% CI, unique name, ≤140-character note, and a promote/negative verdict.
