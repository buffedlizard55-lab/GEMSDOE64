2. Upload

  1. Click the blue DOWNLOAD button on the home page. You get a single-band GeoTIFF (.tif). The .zip next to it contains the same one TIFF if you prefer to upload a zip.
  2. Open the competition submission page and press New submission.
  3. File to submit: choose the downloaded .tif (or the .zip).
  4. Note (optional): paste the note shown on the home page (≤140 characters) so the run is recognisable later.
  5. Press submit. The portal re-checks CRS, shape, geotransform and value range.

3. What the portal checks (and what we pre-checked)

  • single band, float32
  • shape 3730 × 3292, CRS EPSG:32611, transform (100, 0, 243350, 0, -100, 4508550) — 100 m pixels
  • every finite value inside [0, 1]; the writer is fail-closed and refuses to clip, fill or repair anything
  • all-finite export (no NaN anywhere): outside-footprint cells are 0.0, matching this family's accepted -zeros submissions. The organiser's own sample_submission.tif uses NaN outside the footprint; both encodings have been accepted by the portal for this family, and the metric is evaluated inside the footprint.
  • zero positive mass on mapped catalogue pixels (they are masked out of scoring, so a dot there is pure false-positive mass)

4. Naming convention

gems64-<method>-<UTC stamp>-<12-hex array digest>-zeros.tif. The digest is the sha256 of the decoded pixel array, so two files with the same name suffix are the same raster.
