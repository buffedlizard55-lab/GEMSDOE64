Objective

The score is a distance-weighted Tversky index with alpha = 0.2, beta = 0.8 and a 300 m (3 px) triangular kernel. Because FNw = |G| − TPw,

DTI = T / (0.2*(T + F) + 0.8*|G|)

Adding one unit-mass dot at x changes T by dT = sum_g w_g max(0, k(x,g) - C_g) and F by dF = 1 - E[max_g k(x,g) B_g]. The exact accept test is dT > alpha*T*dF / (alpha*F + beta*|G|), which for a non-redundant dot reduces to kappa > alpha*DTI (0.06 at DTI 0.30). Adjacent picks are redundant under the 3-px kernel, so pixels are never thresholded independently: the greedy tracks the running credit field C and the backward prune removes any dot whose removal raises DTI.
