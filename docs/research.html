With T = TP, F = FP and K = truth count, the shared kernel metric gives D = α(T+F)+βK when α+β=1. Deleting a dot with lost true credit t and saved false credit f improves the realized ratio exactly when

(1 − α S) t < α S f,  where S = T / D.

Thus deletion helps if it saves penalty with little loss of unique coverage. Known-fault-adjacent predictions may spend mass on already explained structures; a sparse layout may reduce kernel redundancy. But distance to a known fault is not proof that an unseen splay is absent. The 200 m pruning rule can also delete real hidden continuations. We cannot attribute an organizer score to any of these mechanisms without hidden truth or a defensible independent experiment.

The threshold claim: a necessary correction

For independent binary decisions without spatial credit, define the ratio of expected counts

S(A) = sum(i in A) p_i / [α |A| + β sum(i) p_i].

Adding a cell improves this surrogate iff p_i > α S(A). At an optimum, the threshold is α S*; for F1, α=β=1/2. At a hypothetical surrogate value 0.30, α=0.2 gives the arithmetic threshold 0.06. Those are hypothetical mathematical values, not a measured HOLDOUT-DTI or competition score.

We checked 204,800 additions across 200 probability vectors and all their 256 subsets: no surrogate-rule contradictions. But expectation of a ratio is not generally the ratio of expectations. Exhaustive enumeration of four Bernoulli truths found a counterexample: the proposed pixel probability exceeds α times the exact expected score, while the exact expected score decreases. The probabilities and all calculations are in evidence/synthetic_verification.json. This falsifies the unrestricted finite-raster claim; it does not falsify the population/surrogate F1 result attributed to Lipton, Elkan and Narayanaswamy. Primary-author preprint link, not fetched here.

For the shared spatial metric, truth coverage is a maximum over predictions, whereas the FP term sums prediction costs. A new dot may cover many truth cells; its ΔTP can exceed its nearest-truth credit and even one. The correct realized inclusion test is

ΔTP > α S [ΔTP + 1 − nearest_truth_kernel_credit].

A scalar calibrated probability cannot encode redundancy or the joint spatial truth distribution. The reference selector therefore averages each draw's actual ratio, re-evaluates all additions, and then removes dots while removal increases the mean. It does not assume submodularity for lazy updates. Thirty-two synthetic jittered line rasters verified exact agreement with the literal brute-force metric oracle. They are not trained ensemble/TTA/MC-dropout outputs, not calibration evidence, and never a holdout score. The reference implementation has explicit size/time limits and is not a production-scale optimizer.

Range-error response and limitations

The user's earlier file was not supplied, so its rejection cause is unknown. Possibilities include nodata sentinels, unnormalized output, infinity, or NaN inside the footprint. This writer never silently clips/repairs model output. Binary dots are already in [0,1]; all-finite zero-outside export is stricter than “NaN only outside,” so no NaN can leak inside. It checks float32, EPSG:32611, 100 m pixels, exact shape/affine, footprint, catalogue masking, nonempty support, and the serialized TIFF and ZIP. Tests deliberately reject bad range/sentinels and verify a synthetic round-trip fixture, but no production validator pass is claimed. A local format pass is not organizer acceptance.

The official reference README explicitly supports CPU-only execution. “GPU needed” and “only blocker is data placement” are not accurate descriptions of this checkout. The notebook's Tversky training loss is not an official spatial-DTI test oracle. We verified internal metric arithmetic against a separate literal implementation, not a live organizer test endpoint.
