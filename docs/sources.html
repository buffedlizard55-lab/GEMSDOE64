Problem description, page 967 The exact metric — TP_w = Σg∈G maxx p(x)k(d(x,g)), FP_w = Σx:p>0 p(x)[1 − maxg k(d(x,g))], FN_w = Σg[1 − maxx p(x)k(d(x,g))], DTI = TP_w/(TP_w + 0.2FP_w + 0.8FN_w); triangular kernel R = 300 m; worked example 3.00/1.89/2.00 → 0.60; submission format (EPSG:32611, 100 m, same bounds, single float32 layer in [0,1], higher = more probable, sample = total fault absence) Read live 2026-10-11, both chunks. The metric is re-implemented verbatim in scripts/build_scarp_stage2.py::metric_terms and cross-checked against src/gems57/metric.py.
