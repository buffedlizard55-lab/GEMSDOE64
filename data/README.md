# Local competition data (not committed)

Place competition files obtained through authorized DrivenData access here. The data tab currently redirects this environment to its login page, so this directory intentionally contains no downloaded competition data.

Expected files from the project brief include `training_features.tif`, `labels.tif`, `sample_submission.tif`, and `1m_DEM_links.csv`. Their presence, CRS, shape, transform, band metadata, and nodata conventions must be verified from the actual files before any model or submission is run. Do not add account credentials, cookies, access tokens, or private session material here.

Large inputs and generated runs are excluded from Git by the repository `.gitignore`. The exact shared template, evaluator, writer, and validator are also absent from this checkout; do not replace them with a private clone of their behavior.
